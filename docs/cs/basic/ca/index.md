# 计算机组成原理


计算机组成原理是一门介绍计算机是如何将硬件充分利用、与软件高度配合，实现高效性能的学科

因此，在这里，你将需要：

- [ ] 了解硬件和软件资源
- [ ] 如何利用这些资源、提供高效的性能
- [ ] 如何衡量计算机的性能


当学完此系列，你能够知晓并轻松回答这些问题，在现代计算机（手机、电脑等计算机设备）上：

- [ ] 计算机仅仅依靠二进制，是如何呈现如此丰富的内容？
- [ ] 我8+256的手机，到底哪个是内存？
- [ ] 什么？我的冰箱也是一台计算机？
- [ ] 电脑为什么会卡住了，键盘/鼠标没有反应？
- [ ] 为什么很多人跑分用来评判电脑性能，这客观吗？



如果你能够知晓：

你将电脑外置硬盘上的一个文件上传到一个云盘中

这背后计算机软硬件发出了哪些指令，各个硬件如何响应，CPU、内存、硬盘如何定位你需要传输的数据，你的硬盘如何被读写，你的数据如何从硬盘流通至主板、内存（主存）、cache、上CPU、最终通过网络模块传输的

那么恭喜，此系列已经基本被你所掌握。
