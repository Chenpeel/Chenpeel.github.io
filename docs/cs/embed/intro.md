# 嵌入式系统

### 简介

相对通用计算机而言，嵌入式计算机侧重于一些简单逻辑的控制和处理。一般以应用为中心，以计算机技术为基础，软硬件兼顾的专用系统。

### 特点

- 实时性
- 低功耗
- 小尺寸
- 特定功能
- 可靠性
- 成本低

### 硬件

- MPU
- MCU
- 存储器（Flash、RAM、EEPROM）
- I/O接口
- 电源管理组件
- 时钟和震荡器
- 数字、模拟信号的互转（ADC、DAC）

#### 处理器

> 随着大规模集成电路的发展，微型计算机系统形成了微处理器（Micro Processor Unit, MPU）和微控制器（Micro Controller Unit, MCU）两个分支。

##### 微处理器（MPU）

高性能的处理器，作为微型计算机的核心部件，决定了计算机的计算性能，其发展速度迅猛。通常应用于高速数据处理和运算（如手机处理器、智能家居设备处理器）。

##### 微控制器（MCU）

将微处理器、存储器和外围接口集成在单个芯片上的集成电路（单片机）。主要应用于控制领域，其构成的检测控制系统具有一定的实时性，能快速响应外界、采集数据等信息。

##### 数字信号处理器（DSP）

专用于数字信号处理的芯片，适用于处理音视频、通讯等。

##### 可编程逻辑器件（FPGA）

可编程的逻辑芯片，可用于数字电路设计、信号处理、电路验证等。

##### 图形处理器（GPU）

专用于图形处理、矩阵运算等。

### 指令集架构

#### 指令

指令是由用户程序或内核程序发出，由处理器这类硬件资源在一定的时钟周期内，对存储在内存、寄存器中的内容进行一系列操作的微指令响应。简单来说，就是软件程序对硬件资源的支配命令，一般近似等价于汇编语言中的一条指令，如下：无条件转移指令。

```cpp
JMP 0x7c00
```

但不同的指令可能对应的二进制位数是不同的，一些指令需要对多个地址的内容进行访问和存取，而另一些指令则可能根本无需地址访存，指令中不需要地址。

计算机所使用的指令也会有概率上的集中趋势，程序运行具有空间局部性和时间局部性。

#### 指令集

计算机系统所使用的所有指令的集合。x86系列处理器的问世可见，现在的复杂指令集使用微指令流水线的方式，一定程度上兼顾了精简指令的优点。

##### 复杂指令集

计算机指令结构是复杂指令的集合，单个指令就能完成指令的寻址、存取、运算多个操作，指令的长度不一。

在精简指令集诞生之前，并不存在复杂指令这一概念，因此基于复杂指令集的计算机（Complex Instruction Set Computer, CISC）是相对RISC术语追述创造的，它成为指代所有非RISC总称。

###### x86

x86架构泛指一系列基于Intel 8086且向后兼容的CPU指令集架构。由于早期 Intel以86作为处理器命名结尾，因此其架构称为x86，而由于数字不能作为商标注册名称，80486其后的新一代注册为Pentium（奔腾）。

8086处理器采用微指令的方式，借鉴了RISC的五段式流水线，一定程度上提升了指令的执行效率。

##### 精简指令集

相对复杂指令集而言，多条简单指令可以完成一条复杂指令的任务，精简指令的长度较为统一，每条精简指令只执行一项功能。

指令的可预测性提升，流水线方式使得指令执行的速度得到了提升。

基于精简指令的计算机（Reduced Instruction Set Computer, RISC）始于1970年代后期，随着RISC开源架构的不断成熟，在1980年代中后期和1990年代初期，许多类似设计问世，ARM架构（Advanced RISC Machine）就是其中典型代表之一。

###### ARM

由于其成本低、功耗低、发热量低，ARM处理器适用于轻型、便携、电池供电的设备，如智能手机、笔记本电脑、平板电脑以及嵌入式系统，也可用于台式机和服务器设备。
