# 嵌入式系统

### 简介

相对通用计算机而言，嵌入式计算机侧重于一些简单逻辑的控制和处理。一般以应用为中心，以计算机技术为基础，软硬件兼顾的专用系统。

### 特点

- 实时性
- 低功耗
- 小尺寸
- 特定功能
- 可靠性
- 成本低

### 硬件

- MPU
- MCU
- 存储器（Flash、RAM、EEPROM）
- I/O接口
- 电源管理组件
- 时钟和震荡器
- 数字、模拟信号的互转（ADC、DAC）

#### 处理器

> 随着大规模集成电路的发展，微型计算机系统形成了微处理器（Micro Processor Unit, MPU）和微控制器（Micro Controller Unit, MCU）两个分支。

##### 微处理器（MPU）

高性能的处理器，作为微型计算机的核心部件，决定了计算机的计算性能，其发展速度迅猛。通常应用于高速数据处理和运算（如手机处理器、智能家居设备处理器）。

##### 微控制器（MCU）

将微处理器、存储器和外围接口集成在单个芯片上的集成电路（单片机）。主要应用于控制领域，其构成的检测控制系统具有一定的实时性，能快速响应外界、采集数据等信息。

##### 数字信号处理器（DSP）

专用于数字信号处理的芯片，适用于处理音视频、通讯等。

##### 可编程逻辑器件（FPGA）

可编程的逻辑芯片，可用于数字电路设计、信号处理、电路验证等。

##### 图形处理器（GPU）

专用于图形处理、矩阵运算等。
